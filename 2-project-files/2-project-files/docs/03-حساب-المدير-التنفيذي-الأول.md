# إنشاء حساب المدير التنفيذي الأول بصورة آمنة

الحساب الأول لا يُنشأ من صفحة تسجيل عامة (غير موجودة أصلًا)، بل من جهازك بسكربت يستخدم مفتاح الخدمة مرة واحدة.

## الخطوات

1. تأكد أن `.env.local` على جهازك يحتوي:
   ```
   NEXT_PUBLIC_SUPABASE_URL=...
   SUPABASE_SERVICE_ROLE_KEY=...
   ```
2. شغّل:
   ```bash
   npm run create-admin -- --email ed@rawasim.org --name "عبدالملك الدريهم"
   ```
3. أدخل كلمة مرور قوية (12 حرفًا على الأقل) مرتين؛ لا تظهر أثناء الكتابة ولا تُحفظ في أي ملف.

## ما يفعله السكربت

- يتحقق من الاتصال وتطبيق الترحيلات.
- **يرفض** إنشاء مدير تنفيذي ثانٍ إذا وُجد مدير نشط (إلا مع `--force` عن قصد).
- يكتب الدور في `app_metadata` التي لا يستطيع أي مستخدم تعديلها بنفسه، فيُفعَّل الحساب بدور «المدير التنفيذي».

## بعد الإنشاء

- سجّل الدخول، ثم أضف بقية المستخدمين من **الإعدادات ← المستخدمون**.
- يُنصح بإضافة **مسؤول نظام** لإدارة الحسابات تقنيًا دون صلاحيات القرار.
- احذف `SUPABASE_SERVICE_ROLE_KEY` من جهازك إن لم تعد تحتاجه محليًا (يبقى في إعدادات Vercel فقط).
- لتغيير كلمة المرور لاحقًا: صفحة **حسابي** (بالضغط على اسمك أسفل القائمة).
