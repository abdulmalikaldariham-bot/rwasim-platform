# دليل المستخدمين المختصر

## المدير التنفيذي

**صفحتك الرئيسية: لوحة الأداء.** ابدأ من الطبقات (إنجاز كل إدارة)؛ العلامة الرأسية الداكنة في كل طبقة = المخطط حتى اليوم. اضغط أي إدارة للتعمق إلى أنشطتها، ثم أي نشاط لخطواته.

**مركز المتابعة التنفيذية** (لك وحدك):
- *ما الذي يحتاج تدخلك؟* الأنشطة المتعثرة، التأخر المؤثر مرتبًا بأثره على إنجاز الجمعية، المؤشرات المنحرفة، الإدارات التي لم تحدّث بياناتها، القرارات المطلوبة المرفوعة من الفرق.
- *الاعتمادات:* الخطط المرفوعة، طلبات تعديل الأوزان والهيكل، التقارير بانتظار المراجعة.
- *التوجيهات:* «توجيه جديد» ← اربطه بإدارة أو نشاط أو مؤشر وحدد المسؤول والموعد. المسؤول يحدّث المعالجة، وأنت تغلق.

**اعتماد خطة:** افتح الخطة ← راجع الملاحظات ← «اعتماد الخطة» أو «إعادة للتعديل» مع السبب. لا يمكن اعتماد خطة أوزانها لا تساوي 100٪.

**التقارير:** التقارير ← اختر النوع والفترة والنطاق ← «إصدار التقرير» ← اكتب تعليقك وتوصياتك ← «اعتماد التقرير». بعد الاعتماد لا يتغير التقرير أبدًا.

## مدير الإدارة

**صفحتك الرئيسية: مساحة عمل الإدارة.**
- *هذا الأسبوع:* المتأخرة أولًا ثم مهام الأسبوع. «تم الإنجاز» يسجل الاكتمال بنقرة، و«تحديث» لإضافة ملاحظة أو شاهد أو تعليق المهمة أو رفع تعثر للمدير التنفيذي.
- *الشهر:* بطاقة لكل أسبوع؛ الخطوة الممتدة عدة أسابيع تظهر في كل أسبوع لكنها سجل واحد.
- *المسؤول:* صفِّ المهام حسب الشخص.

**إعداد خطة الربع:**
1. الخطط ← «استيراد من Excel» (أو «إنشاء يدوي»، أو «تنزيل قالب Excel»).
2. راجع الأوراق والمسؤولين والمخرجات والأسابيع، واحفظ كمسودة.
3. «ضبط الأوزان»: وزن كل نشاط (المجموع 100٪)، ثم داخل كل نشاط حدد الخطوة الجوهرية (النجمة = 40٪) أو «تطبيق القاعدة المقترحة». قسّم الخطوة الكبيرة إلى مراحل فرعية بزر المقص.
4. «حفظ ورفع للاعتماد».

**التفويض:** في صفحة النشاط اختر الموظف بجانب الخطوة؛ تظهر له في «مهامي».

**بعد الاعتماد:** التحديثات اليومية مباشرة. تعديل الأوزان أو إضافة خطوات أو تغيير الجدولة يُرسل «طلب تعديل» للمدير التنفيذي.

## الموظف المفوض

**صفحتك: مهامي.** ترى المهام المسندة إليك فقط: المتأخرة، وهذا الأسبوع، والشهر، والمنجزة.
- «تم الإنجاز» عند الانتهاء.
- «تحديث» لإرفاق شاهد (صورة، PDF، مستند) أو كتابة ملاحظة أو رفع تعثر.

## عضو مجلس الإدارة

لوحة الأداء بمحوريها، والتعمق في الإدارات والأنشطة المعتمدة، والخطة التنفيذية، والتقارير المعتمدة. صلاحيتك قراءة فقط.

## مسؤول النظام

الإعدادات ← المستخدمون: إضافة الحسابات، تعديل الأدوار والإدارات، التعطيل، كلمات المرور المؤقتة. سجل التغييرات للمراجعة. قرارات الهيكل والأوزان للمدير التنفيذي.

## مصطلحات الحالة

| الحالة | المعنى |
|---|---|
| مكتمل | كل الخطوات منجزة |
| جارٍ | بدأ العمل ولم يتأخر |
| متأخر | خطوة تجاوزت موعدها ولم تكتمل |
| متعثر | تأخر أكثر من 14 يومًا أو خطوة معلّقة |
| لا توجد بيانات | لا توجد خطة معتمدة — لا يُعرض صفرًا |
| لم تُحدّث البيانات | خطة معتمدة وأعمال مستحقة ولم يُسجل أي تحديث |
| بيانات قديمة | آخر تحديث أقدم من المدة المحددة في الإعدادات |
