# التشغيل محليًا

## المتطلبات

- Node.js 20.9 أو أحدث (اختُبر على 22).
- أحد خيارين لقاعدة البيانات:
  - **أ) Supabase CLI مع Docker** (الأسهل): `npx supabase start`.
  - **ب) مشروع Supabase سحابي مخصص للتطوير** (مجاني).
- لتوليد PDF محليًا: Google Chrome أو Chromium مثبت (يُحدد مساره في `CHROMIUM_PATH`).

## الخطوات (الخيار أ: Supabase محلي)

```bash
npm install
npx supabase start            # يطبق كل ملفات supabase/migrations تلقائيًا
npx supabase status           # انسخ API URL و anon key و service_role key
cp .env.example .env.local
```

املأ `.env.local`:

```
NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
NEXT_PUBLIC_SITE_URL=http://localhost:3000
CHROMIUM_PATH=/Applications/Google Chrome.app/Contents/MacOS/Google Chrome   # macOS مثلًا
```

ثم:

```bash
npm run create-admin -- --email ed@example.org --name "المدير التنفيذي"
npm run dev
```

افتح http://localhost:3000 وسجّل الدخول.

## بيانات تجريبية (اختياري، محلي فقط)

لتجربة كل الأدوار ببيانات الربع الرابع 2026 المستوردة من الملف المرجعي:

```bash
set -a; source .env.local; set +a
npx tsx scripts/local-dev/seed-demo.ts
```

ينشئ حسابات `@demo.rawasim.local` (كلمة المرور `Demo-Rawasim-2026`) ويعلّم كل تحديث تجريبي بعبارة «[تجريبي]». السكربت يرفض العمل على أي رابط غير محلي. **لا تشغله على قاعدة الجمعية الفعلية.**

## الاختبارات

```bash
npm test                    # محرك الاحتساب والأوزان والاستيراد (45 اختبارًا)
npm run typecheck && npm run lint

# اختبارات التكامل على قاعدة Supabase فارغة (تنشئ مستخدمين وبيانات ثم تحذف المستخدمين)
TEST_SUPABASE_URL=... TEST_SUPABASE_ANON_KEY=... TEST_SUPABASE_SERVICE_KEY=... npm run test:integration

# اختبار الواجهة بمتصفح حقيقي (بعد زرع البيانات التجريبية وتشغيل الموقع)
node tests/e2e/ui-flow.mjs ./shots
```

## بيئة دون Docker

في `scripts/local-dev/` سكربت `reset-db.sh` الذي استُخدم أثناء التطوير لتشغيل المكونات (PostgreSQL وSupabase Auth وPostgREST وStorage) مباشرة دون Docker. هذا مسار متقدم؛ الأسهل هو Supabase CLI.
