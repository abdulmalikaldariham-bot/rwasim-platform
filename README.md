# رواسم | منصة الأداء المؤسسي

منصة ويب داخلية لجمعية رواسم لإدارة الخطة التنفيذية السنوية والخطط التشغيلية الربعية، ومتابعة الإنجاز أسبوعيًا، وقياس المؤشرات، وإصدار التقارير.

## ما الذي تقدمه

| القسم | لمن | ماذا يفعل |
|---|---|---|
| لوحة الأداء المؤسسي | الجميع حسب الصلاحية | محوران منفصلان: الأداء التشغيلي (إنجاز الأعمال) والأداء التنفيذي السنوي (تحقيق المؤشرات)، مع التعمق: الجمعية ← الإدارة ← النشاط ← الخطوة |
| مركز المتابعة التنفيذية | المدير التنفيذي فقط | ما يحتاج تدخلك، الاعتمادات، التوجيهات ومتابعة إغلاقها |
| مساحة عمل الإدارة | مدير الإدارة | مهام الأسبوع والشهر والمتأخرة، التصفية حسب المسؤول، آخر التحديثات |
| مهامي | الموظف المفوض | مهامه فقط، إكمال بنقرة، ملاحظة وشاهد |
| متابعة الأنشطة | المدير التنفيذي، المديرون، المجلس | بطاقات الأنشطة الذكية وتفاصيلها |
| الخطط التشغيلية | المدير التنفيذي، المديرون | استيراد Excel بمعالج، إنشاء يدوي، شاشة الأوزان، الاعتماد، إعادة الاستيراد، طلبات التعديل |
| الخطة التنفيذية | المدير التنفيذي (تحرير) والبقية (اطلاع) | المحاور والأهداف والمؤشرات والمستهدفات والقياسات |
| التقارير | المدير التنفيذي والمديرون والمجلس | شهري/ربعي/سنوي، شامل أو لإدارة، PDF وExcel، نسخة ثابتة، تعليق واعتماد |
| الإعدادات | المدير التنفيذي ومسؤول النظام | السنوات، الإدارات، أوزان الإدارات، حدود الأسابيع، المستخدمون، سجل التغييرات |

## التقنية

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · مكونات بأسلوب shadcn/ui فوق Radix · Supabase (PostgreSQL + Auth + Storage) · Recharts · ExcelJS · Puppeteer/Chromium لتوليد PDF عربي · Vitest.

## هيكل المشروع

```
supabase/migrations/   مخطط قاعدة البيانات، الدوال، سياسات RLS، التخزين والبيانات المرجعية
src/lib/engine/        محرك احتساب الإنجاز والأوزان والمؤشرات (TypeScript نقي ومختبر)
src/lib/import/        قارئ Excel للخطط التشغيلية والتنفيذية، المقارنة، القوالب
src/lib/reports/       بناء لقطة التقرير، الوثيقة، PDF، Excel
src/app/(app)/         صفحات المنصة
src/app/actions/       إجراءات الخادم (كلها بجلسة المستخدم وتخضع لـ RLS)
tests/                 اختبارات الوحدات، التكامل على Supabase حقيقي، والواجهة بمتصفح
scripts/               إنشاء المدير التنفيذي الأول، النسخ الاحتياطي والاستعادة، أدوات التطوير المحلي
docs/                  الأدلة
```

## البدء السريع

```bash
npm install
cp .env.example .env.local      # ثم املأ مفاتيح Supabase
npx supabase db push            # أو نفّذ ملفات supabase/migrations بالترتيب
npm run create-admin -- --email you@rawasim.org --name "الاسم"
npm run dev
```
